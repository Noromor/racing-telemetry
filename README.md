# Апекс-лог

Учебный сайт по дисциплине «Веб-аналитика» (Московский Политех, гр. 233-321).
Тема - телеметрия популярных гоночных трасс: схемы, апексы, графики скорости/газа/тормоза.

Вся телеметрия демонстрационная, считается скриптом в `js/data.js`.

Сайт статический, открывается просто из папки или через GitHub Pages.
Ссылки относительные, так что работает и из подпапки.

- `tracks/` - страницы трасс
- `files/` - CSV с апексами и гайд
- `stats/` - отчёты по логам (тестовый трафик на локальной копии под nginx)
