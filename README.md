# Апекс-лог

Статический сайт о телеметрии гоночных трасс: схемы, точки апексов, графики скорости, газа и тормоза,
расписание гонок на выносливость 2026 и раздел о симрейсинге.

Графики телеметрии строятся скриптом `js/data.js` по скоростям в апексах. Линии трасс для анимации
(`js/paths.js`) сняты с исходных SVG Wikimedia Commons.

- `tracks/` - страницы трасс
- `files/` - CSV с апексами и гайд
- `stats/` - отчёты по журналам веб-сервера (тестовый трафик на локальной копии под nginx)
