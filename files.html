Файлы

Данные сайта в открытых форматах.

CSV открываются в Excel или LibreOffice Calc, данные можно использовать для собственных графиков.

Точки апексов (CSV)

  • apex_monza.csv - Монца, все классы
  • apex_spa.csv - Спа-Франкоршам, все классы
  • apex_suzuka.csv - Сузука, все классы
  • apex_silverstone.csv - Сильверстоун, все классы
  • apex_nurburgring.csv - Нюрбургринг Нордшляйфе, все классы
  • apex_monaco.csv - Монако, все классы
  • apex_all.csv - все трассы и классы одним файлом

Кодировка UTF-8, разделитель - запятая. Колонки: track, class, turn_no, turn_name, distance_m, apex_speed_kmh, gear. Класс: f1, hypercar, lmp2, lmp3, gt3.

Телеметрия круга (CSV)

  • telemetry_monza.csv - Монца, все классы; по классам: F1, Hypercar, LMP2, LMP3, GT3
  • telemetry_spa.csv - Спа-Франкоршам, все классы; по классам: F1, Hypercar, LMP2, LMP3, GT3
  • telemetry_suzuka.csv - Сузука, все классы; по классам: F1, Hypercar, LMP2, LMP3, GT3
  • telemetry_silverstone.csv - Сильверстоун, все классы; по классам: F1, Hypercar, LMP2, LMP3, GT3
  • telemetry_nurburgring.csv - Нюрбургринг Нордшляйфе, все классы; по классам: F1, Hypercar, LMP2, LMP3, GT3
  • telemetry_monaco.csv - Монако, все классы; по классам: F1, Hypercar, LMP2, LMP3, GT3
  • lap_times.csv - расчётное время круга по трассам и классам и реальные ориентиры

Файл всех классов: distance_m и по три колонки на класс (f1_speed_kmh, f1_throttle_pct, f1_brake_pct, hypercar_speed_kmh, ...). Файл одного класса: distance_m, speed_kmh, throttle_pct, brake_pct. Шаг - 10 м.
